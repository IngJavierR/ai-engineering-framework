# AI Engineering Framework v0.8.0-rc.1

## Estado de publicación

Release candidate preparada localmente. El tag, push y GitHub Release requieren
autorización explícita.

## Cambios

- **DDD obligatorio en backend.** La skill `backend-ddd-architecture` define el
  estándar neutral al stack: capas `domain`, `application`, `infrastructure` e
  `interfaces`, regla de dependencias, bounded contexts, validación y reporte.
  Cada stack lo mapea a su estructura concreta en `references/ddd-layout.md`.
- **Estándares de stack como skills.** `java.instructions.md` pasa a la skill
  `java-spring-development`, igual que `fastapi-development`. No quedan
  instrucciones con alcance por lenguaje.
- **Preparado para nuevos stacks.** `stack-layout-contract.md` enumera lo que
  un stack nuevo (por ejemplo .NET) debe definir y los pasos para registrarlo.

## Aplicación del estándar DDD

| Caso | Regla |
| --- | --- |
| Proyecto backend nuevo | DDD obligatorio desde el primer commit |
| Bounded context o módulo nuevo en proyecto existente | DDD obligatorio para el código nuevo |
| Código existente sin DDD | Sin refactor sin aprobación; cambio mínimo y brecha reportada |

## Compatibilidad

Cambio incompatible para consumidores con locks que contienen
`.github/instructions/java.instructions.md` o
`.github/skills/openapi-to-ddd/references/ddd-structure.md` (perfil
`java-spring`, base `java-base` y locks v0.2.0/v0.3.0). Migración revisada:

```bash
python3 tools/install.py --target <consumidor> --profile java-spring --upgrade --migrate-stack --dry-run
python3 tools/install.py --target <consumidor> --profile java-spring --upgrade --migrate-stack
```

El dry-run lista los artefactos que se retiran. El instalador verifica los
hashes locales antes de retirarlos y falla si fueron modificados.

Los perfiles `python-fastapi` y `backend` reciben artefactos nuevos sin retirar
ninguno; basta con `--upgrade`.

Las reglas de `openapi-ddd` y `liquibase` ya no se adjuntan automáticamente al
editar archivos `.java`. Las reglas obligatorias equivalentes viven en la
gobernanza universal y en las skills de stack.
