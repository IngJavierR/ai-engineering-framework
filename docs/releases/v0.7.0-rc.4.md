# AI Engineering Framework v0.7.0-rc.4

Release candidate preparada localmente. El tag, push y GitHub Release requieren
autorización explícita.

## Correcciones

RC4 corrige R1–R9: defaults multi-stack de artefactos ignorados, rendimiento del
guard Git, ramas de feature, alcance seguro en monorepos, contratos sin copias,
quickstarts literales y la receta Compose de Liquibase.

## Compatibilidad

Los nuevos defaults son aditivos y permanecen sujetos a la validación
fail-closed de `ignoredWorkPaths`. Los receipts RC3 sin campos nuevos conservan
la validación existente.
