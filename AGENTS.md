
# AI Engineering Framework

## Purpose

This repository contains a versioned engineering
framework for GitHub Copilot.

Its goal is to standardize AI-assisted software
development across multiple projects and clients.

## Core Principles

1. Engineering standards must be explicit,
   versioned and auditable.

2. AI-generated code must comply with the
   applicable project and client policies.

3. Reusable capabilities must be modular.

4. Changes must be incremental and traceable.

5. Never introduce breaking changes without
   documenting their impact.

6. Never modify unrelated functionality.

7. Keep documentation synchronized with changes.

8. Never claim that a validation passed
   unless it was actually executed.

## Framework Development Rules

- Treat this repository as a reusable product.
- Do not implement application-specific business logic.
- Avoid hardcoding client-specific requirements.
- Prefer configuration over duplication.
- Preserve backward compatibility when possible.
- Document architectural decisions.
- Do not create unnecessary components.

## Current Scope

The framework is in its initial MVP stage.

Do not implement future capabilities unless
explicitly requested.
